# Security reporting

Do not put node tokens, private keys, or exploit details in a public issue.
Use GitHub's private vulnerability reporting feature if enabled for this
repository. If it is unavailable, ask the maintainer for a private reporting
channel without publishing sensitive details.

This repository packages upstream Wings. Report vulnerabilities in Wings
itself through the upstream project's security reporting process.

Release artifacts are checksum-verified, but checksums are not publisher
signatures. Trust the repository/release source and review changes before
running the root installer. See the README for runtime test coverage.
